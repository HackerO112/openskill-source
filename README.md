## 🚀 What is it?

**OpenSkill** is a free, open, Skillshare-style learning site for anyone. Pick any skill — from programming to knitting to car repair — and get a structured **"zero to master" course** built from the best teachers on YouTube.

### How it works
Courses are **assembled automatically**. The site searches YouTube, ranks videos by views, likes, and creator reputation, and uses AI to order the clearest lessons into **Beginner → Master** levels. You never have to hunt through playlists or wonder which video to watch next — OpenSkill builds the curriculum for you.

### Privacy by design
- ✅ **No accounts required** — pick a skill and start learning immediately.
- ✅ Progress, notes, and streaks are **saved in your browser**, never uploaded.
- ✅ **Export/Import** your data to move between devices.
- ✅ Courses build on first open and are reused for everyone after.

## 🧭 How to use

1. **Browse** the skill directory or search for what you want to learn.
2. **Open a skill** — OpenSkill assembles a zero-to-master course automatically (first open builds it, reopens reuse it).
3. **Learn** lesson by lesson with the embedded YouTube player.
4. **Track** your progress, notes, and streak in **My Learning**.
5. **Export** your data anytime to import on another device.

## 🏗️ Tech stack

- **React 18** + **TypeScript** — UI and type safety
- **Vite** — fast dev server and production build
- **Tailwind CSS** + **Radix UI** + **Framer Motion** — styling, accessible components, animations
- **Lucide React**, **Sonner**, **React Hook Form**, **Zod**, **TanStack Query**, **Recharts**, **Tiptap**
- **React Router** — multi-page app (Home, Explore, Build, Course, Lesson, My Learning, Source)
- **YouTube API** — video search, ranking, and embedded playback
- **Gemini API** (@google/generative-ai) — AI lesson ordering and course assembly
- **ZiteJS** — app runtime, backend, auth, and sync

## 🛠️ Run it locally

```bash
# install dependencies
yarn install

# start the dev server
yarn dev

# build for production
yarn build

# preview the production build
yarn preview
```

Requires **Node.js** and **Yarn**.
